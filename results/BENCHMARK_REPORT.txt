RECOMMENDATIONS
================================================================================

Workload Matching:
  • Small files (< 1MB): Use Local SSD for lower latency
  • Single-threaded workloads: Use Local SSD (2-5 GB/s)
  • Multi-threaded/high-concurrency: Use NFS with QD=128 (30+ GB/s)
  • Large file transfers: Use NFS with Direct I/O and QD=128

Configuration Tips:
  • For NFS: Always use Direct I/O for high-concurrency workloads
  • For Local SSD: QD=128 provides 2x improvement over QD=1
  • Buffered I/O on NFS doesn't scale well with high queue depth
